# Brain path planner: прототип системы поддержки решений

Сегментация опухоли мозга по МРТ и расчёт кандидатов траекторий до неё.
**Не медицинское изделие.** Учебный прототип для KIMEP AI Challenge.

Демо: https://huggingface.co/spaces/dimxwis1/brain-path-planner

## Что делает проект
1. Берёт МРТ мозга (4 последовательности) из открытого датасета.
2. Готовая модель MONAI `brats_mri_segmentation` выделяет опухоль (ядро, вся опухоль, усиливающаяся часть).
3. Выбирается цель внутри опухоли и перебираются 3000 точек входа на поверхности мозга.
4. Для каждой прямой траектории считаются длина, миллиметры здоровой ткани по пути и угол входа относительно поверхности.
5. Лучшим считается путь с минимальным риском: `здоровая ткань + 0,1 × угол + 0,1 × длина`.

## Результаты
**Сегментация**, 20 случайных случаев (seed 0), модель без дообучения, средний Dice ± std:
- вся опухоль (WT): 0,88 ± 0,13
- ядро (TC): 0,80 ± 0,20
- усиливающаяся часть (ET): 0,75 ± 0,20

В одном случае из 20 (BRATS_184) модель почти не нашла опухоль (Dice WT 0,40). Причину не выясняли.

**Траектории**, 19 случаев (BRATS_184 исключён из-за неудачной сегментации):
- заметное снижение риска (больше 1) в 5 случаях из 19, где кратчайший путь проходит через здоровую ткань;
- в остальных случаях кратчайший путь уже близок к лучшему;
- в 156-м случае лучший путь на 15 мм длиннее кратчайшего: это компромисс, а не чистый выигрыш;
- выбор конкретной точки входа устойчив к весу угла (0 / 0,1 / 0,5) только примерно в половине случаев.

## Ограничения
- Не учтены сосуды, желудочки, функциональные зоны и проводящие пути. Без них путь нельзя считать безопасным.
- Прохождение через опухоль не штрафуется: «0 мм здоровой ткани» не означает безопасность.
- Веса функции риска заданы вручную, не подобраны на клинических данных.
- Снимки без черепа: «поверхность» это поверхность мозга, а не кожа головы.
- Траектории считаются по маске ИИ, а не по разметке врача.
- Модель обучалась на данных BraTS, которые, вероятно, пересекаются с нашими. Это проверка работоспособности, а не независимая валидация, цифры могут быть завышены.
- Порядок каналов входа (T1c, T1, T2, FLAIR) подобран перебором на двух случаях и проверен на 20, этот же набор включает те два случая. Порядок не подтверждён по документации модели.
